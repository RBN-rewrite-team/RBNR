下面我们考虑\(\alpha\mapsto\zeta_\alpha\)的映射。
从0开始重复作用上述映射，所得到的极限就是\(\eta_0\)，基本列
\[\eta_0 = \sup\left\{0, \zeta_0, \zeta_{\zeta_0}, \zeta_{\zeta_{\zeta_0}}, \cdots\right\}\]
\(\eta_0 = \varepsilon_{\eta_0} = \zeta_{\eta_0} \)， 基本列展开方法和\(\zeta_\alpha\)相似，
1.\(\eta_0[0] = 0\)
2.\(\eta_0[n+1] = \zeta_{\eta_0[n]}\)
3.\(\alpha\)为极限序数，\(\eta_\alpha[n] = \eta_{\alpha[n]}\)
4.\(\eta_{\alpha+1} = \beta\mapsto\zeta_\beta\textrm{ fp. aft } \eta_{\alpha}\)
到这里我们能发现这些规则和\(\varepsilon_\alpha, \zeta_\alpha, \eta_\alpha\)
很相似。在各种各样的序数映射之下，不动点的结构可以变得非常复杂。假如我们利用数阵型记号对不动点的层次结构进行标记，那么我们将得到Veblen函数。
最简单的Veblen 函数是只包含一个序数变量\(\alpha\)的一元Veblen函数\(\varphi(\alpha)\)，
它实际上就等于\(\omega^\alpha\)
接下来有二元Veblen函数\(\varphi(\alpha,\beta)\)。
1. \(\varphi(0,\alpha)=\varphi(\alpha)\)
2. \(\varphi(\alpha+1,0)=\beta\mapsto\varphi(\alpha,\beta)\textrm{ fp.}\)
3. \(\varphi(\alpha+1,\beta+1)=\gamma\mapsto\varphi(\alpha,\gamma)\textrm{ fp. }\varphi(\alpha+1,\beta)\)
4. 对于任意极限序数\(\alpha, \varphi(\alpha,\beta+1)=\sup\{\varphi(\gamma,\varphi(\alpha,\beta)+1)|\gamma<\alpha\}\)
5. 对于任意极限序数\(\gamma\), 有\(\varphi(\gamma, 0) = \sup\{\varphi(\beta, 0)|\beta<\gamma\}\)。
例如\(\varphi(1,0) = \beta\mapsto\omega^{\beta} \textrm{ fp.} = \varepsilon_0\),
\(\varphi(1,1) = \gamma\mapsto\omega^\gamma\textrm{ fp. }\varphi(1,0) = \varepsilon_1\),
我们可以推导出\(\varphi(1,\alpha) = \varepsilon_\alpha\)，同样的，\(\varphi(2,\alpha) = \zeta_\alpha\)，\(\varphi(3,\alpha) = \eta_\alpha\)。
