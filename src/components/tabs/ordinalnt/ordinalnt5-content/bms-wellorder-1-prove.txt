证明:
使用 \(BMS\) 定义中的变量名，我们有 \(A = G + B_0 + (C)\) 和 \(A[n] = G + B_0 + B_1 + ... + B_n\)。那么 \(A[n] <_{lex} A\) 当且仅当 \(B_1 + B_2 + ... + B_n <_{lex} (C)\)，如果 \(m_0\) 未定义（空序列在字典序上小于所有其他序列，包括 \((C)\)），这是显然的，否则等价于 \(B_1\) 中的第一列在字典序上小于 \(C\)。
令 \(R_i\) 为 \(B_i\) 中的第一列。由于 \(R_0\) 是 \(C\) 的 \(m_0\)-父级，它对于每个 \(m \le m_0\) 都是 \(C\) 的 \(m\)-祖先，因此 \(R_0\) 的第 \(m\) 个元素小于 \(C\) 的第 \(m\) 个元素。根据定义，\(R_1\) 是 \(R_0\) 的一个副本，但对于每个 \(m < m_0\)，第 \(m\) 个元素增加了 0 或增加了其自身与 \(C\) 的第 \(m\) 个元素之间的差值。那么它小于或等于 \(C\) 的第 \(m\) 个元素，所以 \(R_1\) 的前 \(m_0\) 个元素的序列在逐点意义下小于或等于 \(C\) 的前 \(m_0\) 个元素的序列（实际上，它们是相等的，但这对证明不是必需的）。然而，\(R_1\) 的第 \(m_0\) 个元素必然等于 \(R_0\) 的第 \(m_0\) 个元素，因为 \(m_0 < m_0\) 为假，因此它严格小于 \(C\) 的第 \(m_0\) 个元素。
因此 \(R_1 <_{lex} C\)，这意味着 \(B_1 + B_2 + ... + B_n <_{lex} (C)\)，从而 \(A[n] <_{lex} A\)。
推论 1. 对于所有 \(A, A' \in BMS\)，\(A' < A\) 意味着 \(A' <_{lex} A\)。
