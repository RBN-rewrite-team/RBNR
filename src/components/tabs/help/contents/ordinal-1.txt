序数是数学中用来表示“顺序”的数，它扩展了我们熟悉的自然数(0, 1, 2, 3...)，可以表示无限序列中的位置。
序数具有以下规则：
1. 一个数的下一个数仍然是一个序数
2. 对于任意由序数构成的集合，存在一个最小的序数，它大于这集合中所有的序数。

上述两条规则给出了两种不同的序数，我们分别称之为后继序数和极限序数，它们的具体定义如下：
1. 对任意序数\(\alpha\)，存在一个序数\(\alpha=\alpha+1\)，
我们称之为后继序数。

2. 对于任意由序数构成的序数数列\(\{\alpha_n\}\)，存在一个序数\(\beta\)满足\(\beta = \sup_n\{\alpha_n\}\)
这里，\(\sup\)为上确界，它指的就是大于（或等于）集合中所有元素的最小元素。
我们称\(\beta\)为极限序数，\(\{\alpha_n\} = \{\alpha_0, \alpha_1, \alpha_2, \cdots\}\)
称为\(\beta\)的基本列，记作\(\beta[n] = a_n\)
			
需要注意的是，基本列的指标默认是从 0 开始的，也就是说一个极限序数\(\beta\)应当表示为
\[\beta = \sup_n\{\beta[n]\} = \sup\{\beta[0], \beta[1], \beta[2], \cdots\}\]
现在我们就得到了构造序数的两种方法：对序数取后继，以及选取出一个序数数列并对其取极限。
0 是最小的序数，除了 0 之外，所有的序数都是以上两种情况之一。
从 0 开始，不断取后继，我们就可以得到一个自然数数列
\[\{0,1,2,3,\cdots\}\]
这也是一个序数数列，由这一数列的上确界可以定义一个新的序数
\[\omega = \sup\{0,1,2,3,\cdots\} \]
