RAW:: Prove its contrapositive.
That is, from \(A \neq C\) or \(B \neq D\), deduce \(A \frown (0) \frown B^+ \neq C \frown (0) \frown D^+\).
If \(A \neq C\), then either \(\textrm{length}(A) \neq \textrm{length}(C)\), or there exists \(n < \textrm{length}(A)\) such that \(A_n \neq C_n\).
If \(\textrm{length}(A) \neq \textrm{length}(C)\) (without loss of generality, assume \(\textrm{length}(A) < \textrm{length}(C)\)),
then \((C \frown (0) \frown D^+)_{\textrm{length}(C)} = ((0) \frown D^+)_{0} = 0\).
On the other hand, \((A \frown (0) \frown B^+)_{\textrm{length}(C)} = ((0) \frown B^+)_{\textrm{length}(C) - \textrm{length}(A)} = B^+_{\textrm{length}(C) - \textrm{length}(A) -1} > 0\),
therefore the \(\textrm{length}(C)\)-th terms are not equal, hence \(A \frown (0) \frown B^+ \neq C \frown (0) \frown D^+\).
If there exists \(n < \textrm{length}(A)\) such that \(A_n \neq C_n\), then for that \(n\), we have \((A \frown (0) \frown B^+)_n \neq (C \frown (0) \frown D^+)_n\),
so \(A \frown (0) \frown B^+ \neq C \frown (0) \frown D^+\).
If \(A = C\) and \(B \neq D\), then \(A \frown (0) \frown B^+ = C \frown (0) \frown B^+ \neq C \frown (0) \frown D^+\).
In summary, if \(A \neq C\) or \(B \neq D\), then \(A \frown (0) \frown B^+ \neq C \frown (0) \frown D^+\).

\(P\) is generated from \(E\) and the function \((A,B) \mapsto A \frown (0) \frown B^+\), and Lemma 1.2 asserts free generation (i.e., elements of \(P\) cannot be represented in two different ways).
Since this function is very important in subsequent proofs, abbreviate it as \(\textrm{gen}(A,B) := A \frown (0) \frown B^+\).
